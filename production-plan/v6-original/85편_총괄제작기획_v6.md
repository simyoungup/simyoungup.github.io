# 심업사상 유튜브 동영상 총괄 제작기획서 v6

부제: 현실 사례로 진입하고, 주요 이론을 홍보하며, 최종 편집으로 완성하는 85편 제작체계

기획 주체: 심영업 / 제작기획 보조: 심봉. 언어: 한국어. 대상: 일반 시청자 우선, 연구·실무 시청자 확장. 상태: 제작 총괄 재작성본. 실제 제작·게시·계약·결제·출원자료 공개는 별도 승인.

기준: 사이론 v0.36 강령·용어표·결론, v5 서구 학자 비판 기획, v5 제작 카탈로그. 사이론·집격이론·ULBP·민파/패파·미토·자본주의 무한질주를 주요 기획축으로 두며, 현실 사례는 회차별 사실확인 후 확정한다.

# 요약 결정

- 총량은 본편 40편·쇼츠 40편·특별편 4편·예고 1편, 총 85편으로 유지한다.
- 모든 본편은 현실 질문으로 시작하지만 주홍보이론 1개를 명시한다. 이론은 사례에 부착하는 장식이 아니라 영상의 기억 대상이다.
- 모든 본편은 유관 서구 학자·계승점·비판점·심업사상 보완을 포함한다. 학자 비판은 원전 확인 전 기획 렌즈다.
- 영상 도구는 Floot·YouTube·Runway/ROOT·Synthesia 또는 직접 녹음의 4축으로 구성한다. CapCut·DaVinci는 파일럿 후 하나를 선택한다.
- 최종 품질은 편집·자막·음향·출처·검수에서 결정된다. 생성 도구가 영상을 만들었다고 최종본이 자동 완성되지는 않는다.

# 1. 채널 목적과 편성 원칙

| 항목 | 결정 |
| --- | --- |
| 채널 약속 | 현실의 뜨거운 질문을 심업사상의 이론으로 다시 묻는다. |
| 대중 핵심 이론 | 집격이론·상위레벨 기준점원칙(ULBP)·민파/패파 프레임 |
| 기저 비판 | 이분법적 세계관이 존재론·가치론·인식론을 분리·고정하고, 삼중시간·삼중관점의 동시 작동을 놓칠 수 있다는 사이론의 비판적 가설 |
| 사례 원칙 | 검찰·메가행위자·보잉·플랫폼·금융·AI·미디어·재난 등 실제 사례를 사용하되, 사실·당사자 주장·저자 해석·가설을 구분 |
| 책임 원칙 | 집단행위자=행동, 집단구조=조건, 집격=지속 패턴·품격·책임 귀속. 집격을 사람처럼 결정 주체로 묘사하지 않음(S-17a·S-37). |
| 미토 축 | 자본주의 무한질주의 삼충동 진단과 물질·의식·공정감각의 숙성·제도 전환 가설. 검증된 경제 예측식으로 과장하지 않음. |

영상의 기본 흐름은 현실 질문→사실 확인→서구 학자 이론 소개→계승점·비판→심업사상 보완→비교·반례→시청자 질문이다. 이론의 홍보는 권위 주장보다 “어떤 질문을 새로 할 수 있는가”로 한다.

# 3. 제작 도구 4종과 역할

| 도구 | 현재 상태 | 주 역할 | 사용하지 않을 것 |
| --- | --- | --- | --- |
| Floot | 가입 완료 | 영상 학습 사이트·사례/이론 데이터베이스·이론별/사례별 탐색 | 영상 렌더러로 오해하지 않음 |
| YouTube | 가입 완료 | MP4 저장·스트리밍·재생목록·사이트 삽입 | 원본 편집 프로젝트 보관소로 사용하지 않음 |
| Runway / ROOT | 가입 완료 | 현실 사례를 설명하는 상징적 보조 장면·관계도·AI-FX | 실존 인물·기관의 사실적 재현·사건 증거 위조 |
| Synthesia 또는 직접 녹음 | 사용 경로 확보 | 해설·진행자 음성·도입/정리 | 승인만으로 얼굴·목소리 복제하지 않음 |
| CapCut | 미가입 | 빠른 자막·쇼츠 편집 후보 | 가입 전 최종 도구로 확정하지 않음 |
| DaVinci Resolve | 미가입 | 전문 편집·색·음향 후보 | 가입 전 비용·납품 약속에 포함하지 않음 |

파일럿에서 Synthesia 한국어 음성 샘플과 직접 녹음을 같은 문장으로 비교한다. Runway/ROOT는 1–2개 보조 장면만 시험한다. Floot에는 영상 자체보다 이론 카드·사례 카드·출처·관련 영상 구조를 먼저 만든다. YouTube는 사이트의 플레이어로 삽입하되 85개 플레이어를 동시에 로드하지 않는다.

## 본편 6단 각본 골격

- 0:00–0:20 현실 훅: “검찰총장이 바뀌면 검찰도 바뀌는가?”처럼 사건 질문을 제시한다.
- 0:20–1:00 확인 범위: 무엇이 확인됐고, 당사자 주장은 무엇이며, 아직 모르는 것은 무엇인지 말한다.
- 1:00–2:00 서구 학자: 유관 학자의 문제의식과 성취를 정확히 소개한다.
- 2:00–3:00 비판: 이분법·층위 분리·삼중시간·삼중관점 누락 가능성을 제시하되 학자 전체를 몰아붙이지 않는다.
- 3:00–5:30 주요 이론: 집격이론·ULBP·민파/패파·미토 등 하나를 이름·쉬운 정의·기억문장으로 홍보한다.
- 5:30–7:00 사례 적용: 결정권·연결·이익/비용·응답 통로, 또는 개인·구조·집격을 도식으로 보여준다.
- 7:00–끝 비교·반례·질문: 다른 설명과 당사자 설명을 제시하고 “무엇이 나오면 이 해석을 수정할 것인가?”로 끝낸다.

대본 문장 규칙: “집격이 결정했다” 대신 “집단행위자가 결정했고, 그 결정이 이어진 패턴의 책임을 집격에 묻는다.” “인간이 닫는다” 대신 “인간이 결정한다.” “운행한다”는 필요한 경우 “흐름이 발생한다/작동한다”로 쉬운 말과 병기한다.

# 6. 미토·자본주의 무한질주 연결

힘·돈·멋·CFG·ULBP·사이론·민파/패파 회차에 미토를 연결한다. 자본주의 무한질주는 자기보존·확장·정당화의 삼충동이 물질·의식·공정감각의 제어 없이 양의 되먹임을 이어가는 심업사상의 문명 진단이다. 미토는 단순 붕괴가 아니라 물질 조건과 의식·공정감각이 함께 익어 노동시간·AI 생산성·소유·공유·조세·돌봄·기록·책임·응답 통로를 다시 정하는 전환의 관절이다. 미토 2조건론은 원전 대조 필요 가설로 표시한다.
