# 심업사상 유튜브 동영상 총괄 제작기획서 v7

부제: 현실 사례로 진입하고, 주요 이론을 홍보하며, 최종 편집으로 완성하는 85편 제작체계 — 평가·보강판

기획 주체: 심영업 / 제작기획 보조: 심봉. 언어: 한국어. 대상: 일반 시청자 우선, 연구·실무 시청자 확장. 상태: v6 평가 후 보강본. 실제 제작·게시·계약·결제·출원자료 공개는 별도 승인.

기준: 사이론 v0.36 강령·용어표·결론, v5 서구 학자 비판 기획, v7 제작 카탈로그(`production-catalog-v7.json`). v6 대비 변경점은 `v6_평가보고서.md`에 정리했다.

# v7에서 바뀐 것

- 시즌표를 카탈로그 실제 배치에 맞춰 다시 썼다. v6 시즌표는 S2·S3·S5·S6·S7의 입구·이론이 카탈로그와 달랐다.
- 이론명 표기를 `집격이론`으로 통일했다(카탈로그 4편이 `집격론`).
- 본편마다 대표 학자 1명·핵심 개념 1개·원전 1개를 지정했다. 60초 슬롯에 학자 3–4명을 소개하는 v6 구성은 대본으로 소화할 수 없다.
- v6가 주요 기획축이라 한 미토와 민파/패파를 실제 회차에 연결했다. v5 카탈로그에는 민파/패파가 한 번도 없었고, 미토는 어느 회차에도 연결되지 않았다.
- 시점 재확인 항목(특히 2025년 검찰청 폐지 입법), 법적·피해자 보호 플래그, 제작 용량과 선제작 버퍼, 성과 측정 방법을 추가했다.
- 편성 총량 85편과 이론·사례 선정은 바꾸지 않았다.

# 요약 결정

- 총량은 본편 40편·쇼츠 40편·특별편 4편·예고 1편, 총 85편으로 유지한다.
- 모든 본편은 현실 질문으로 시작하지만 주홍보이론 1개를 명시한다. 이론은 사례에 붙이는 장식이 아니라 시청자가 기억할 대상이다.
- 모든 본편은 대표 서구 학자 1명의 성취·계승점·비판점과 심업사상의 보완을 포함한다. 렌즈의 나머지 학자는 화면 문구나 설명란으로 돌린다. 학자 비판은 원전을 확인하기 전까지 기획 렌즈로만 쓴다.
- 영상 도구는 Floot·YouTube·Runway/ROOT·Synthesia 또는 직접 녹음의 4축으로 구성한다. CapCut·DaVinci는 파일럿 후 하나를 선택한다.
- 공개 개시 전 본편 3편(V01–V03)과 쇼츠 3편을 먼저 완성해 둔다. 최종 품질은 편집·자막·음향·출처·검수에서 결정된다.

# 3. 제작 도구 4종과 역할

| 도구 | 현재 상태 | 주 역할 | 사용하지 않을 것 |
| --- | --- | --- | --- |
| Floot | 가입 완료 | 영상 학습 사이트·사례/이론 데이터베이스·이론별/사례별 탐색 | 영상 렌더러로 오해하지 않음 |
| YouTube | 가입 완료 | MP4 저장·스트리밍·재생목록·사이트 삽입 | 원본 편집 프로젝트 보관소로 사용하지 않음 |
| Runway / ROOT | 가입 완료 | 현실 사례를 설명하는 상징적 보조 장면·관계도·AI-FX | 실존 인물·기관의 사실적 재현·사건 증거 위조 |
| Synthesia 또는 직접 녹음 | 사용 경로 확보 | 해설·진행자 음성·도입/정리 | 승인만으로 얼굴·목소리 복제하지 않음 |
| CapCut | 미가입 | 빠른 자막·쇼츠 편집 후보 | 가입 전 최종 도구로 확정하지 않음 |
| DaVinci Resolve | 미가입 | 전문 편집·색·음향 후보 | 가입 전 비용·납품 약속에 포함하지 않음 |

파일럿에서 Synthesia 한국어 음성 샘플과 직접 녹음을 같은 문장으로 비교한다. Runway/ROOT는 1–2개 보조 장면만 시험한다. Floot에는 영상보다 이론 카드·사례 카드·출처·관련 영상 구조를 먼저 만든다. YouTube는 사이트 플레이어로 삽입하되 85개 플레이어를 동시에 로드하지 않는다.

YouTube 정책 점검(업로드 전 매회):

- 사실처럼 보이는 합성·변형 장면(Runway 장면, Synthesia 아바타)이 있으면 업로드 화면에서 '변경되거나 합성된 콘텐츠' 공개 항목을 켠다.
- 같은 형식의 AI 생성본을 반복 양산하면 수익화 심사에서 반복적·비진정성 콘텐츠로 판정될 수 있다. 회차마다 저자 해설·고유 도식·출처 카드가 들어갔는지 확인한다.
- 재난·참사·성범죄를 다루는 회차(V07·V26·V28·V30)는 광고 적합성이 제한될 수 있다. 수익보다 피해자 보호를 앞에 둔다.
- 정책 문구는 개정이 잦으므로 공개 전 YouTube 고객센터의 최신 정책을 다시 확인한다.

## 본편 각본 골격(8분 기준)

- 0:00–0:20 현실 훅: "검찰 조직의 이름이 바뀌면 검찰도 바뀌는가?"처럼 사건 질문을 던진다.
- 0:20–1:00 확인 범위: 무엇이 확인됐고, 당사자 주장은 무엇이며, 아직 모르는 것은 무엇인지 말한다.
- 1:00–2:00 대표 학자 1명: 핵심 개념 하나와 그 성취를 정확히 소개한다. 렌즈의 다른 학자는 화면 문구로만 표시한다.
- 2:00–3:00 비판: 이분법·층위 분리·삼중시간·삼중관점 누락 가능성을 제시하되 학자 전체를 몰아붙이지 않는다.
- 3:00–5:30 주요 이론: 이론 하나를 이름·쉬운 정의·기억문장으로 홍보한다. 미토·민파/패파 연결 회차는 이 구간 끝 30초를 연결 슬롯으로 쓴다.
- 5:30–7:00 사례 적용: 결정권·연결·이익/비용·응답 통로, 또는 개인·구조·집격을 도식으로 보여준다.
- 7:00–끝 비교·반례·질문: 다른 설명과 당사자 설명을 제시하고 "무엇이 나오면 이 해석을 수정할 것인가?"로 끝낸다.

분량 점검: 한국어 해설은 분당 약 280–320음절이다. 8분 본편 원고는 해설 기준 2,300–2,600자 안팎에서 시작하고, 파일럿 녹음으로 실제 속도를 측정해 고친다.

대본 문장 규칙: "집격이 결정했다" 대신 "집단행위자가 결정했고, 그 결정이 이어진 패턴의 책임을 집격에 묻는다." "인간이 닫는다" 대신 "인간이 결정한다." "운행한다"는 필요하면 "흐름이 발생한다/작동한다"와 쉬운 말로 병기한다.

# 6. 미토·민파/패파 연결

자본주의 무한질주는 자기보존·확장·정당화의 삼충동이 물질·의식·공정감각의 제어 없이 양의 되먹임을 이어가는 심업사상의 문명 진단이다. 미토는 단순 붕괴가 아니라 물질 조건과 의식·공정감각이 함께 익어 노동시간·AI 생산성·소유·공유·조세·돌봄·기록·책임·응답 통로를 다시 정하는 전환의 관절이다. 미토 2조건론은 원전 대조가 필요한 가설로 표시한다.

v6는 이 연결 원칙만 적고 회차를 지정하지 않았다. v7은 무한질주가 사례의 실질 조건인 회차에만 연결 슬롯(30–60초)을 배정한다. 대표회차는 V13, 결산은 VX04다.

- 한국 형법은 사실을 적시해도 명예훼손이 성립할 수 있다(307조 1항). 공익성 위법성 조각(310조)은 '진실+오로지 공공의 이익'을 요구하므로, 실명 기관·개인 회차는 사실·해석·가설의 구분을 대본 문장 단위로 표시한다. 온라인 게시는 정보통신망법 70조 적용 여부도 검토한다.
- 실명 개인은 공적 역할과 공개 기록 범위로 한정한다. 사생활·가족·외모는 다루지 않는다.
- 재난·참사·성범죄 회차(V07·V24·V26·V28·V30·V36)는 한국기자협회 재난보도준칙을 준용한다. 희생자 이미지·실명·유족 발언은 공개 기록이라도 사용 목적을 따로 승인받고, 가능하면 당사자 단체에 사전 설명한다.
- 진행 중 소송·절차(V05·V14·V18·V26·V27·V30)는 결론을 암시하는 제목·썸네일을 금지한다.
- 딥페이크 회차(V25)는 문제 영상을 재게시하지 않고, 설명용 장면은 직접 만든 합성임을 화면에 표시한다.
- 회차별 플래그는 `회차별_검증·법적리스크표_v7.csv`에 있다. '높음' 회차는 공개 전 법률 자문 1회를 권장한다.

1. V01 제목과 사례를 검찰청 폐지 입법의 시행 상태에 맞춰 확정한다(§7 시점 재확인).
